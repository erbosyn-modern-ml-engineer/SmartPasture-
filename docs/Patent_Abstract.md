# Реферат программы для ЭВМ (SmartPasture)

Математическое ядро программы реализует алгоритм многокритериального взвешенного 
индексно-пространственного анализа территории по формуле:
C = 0.25*A + 0.20*B + 0.20*V + 0.15*G + 0.10*D + 0.10*E

Где над входными массивами данных в среде Python (с использованием библиотек NumPy, SciPy) 
производятся следующие операции:
- Переменная A (минерализация, TDS) подвергается нелинейной дискретизации по порогам токсичности для с/х животных;
- Переменная B (глубина залегания) инвертируется и нормализуется методом Мин-Макс для отражения капитальных затрат;
- Переменная V (мощность пласта) и Е (дебит) интерполируются методом радиально-базисных функций (RBF) для построения непрерывного гидродинамического поля;
- Категориальная переменная G (литологический тип коллектора) транслируется в численные коэффициенты пористости;
- Переменная D (пространственная плотность инфраструктуры) рассчитывается через алгоритм поиска k-ближайших соседей (k-NN) и функций плотности для исключения гидродинамического взаимовлияния скважин.

Итоговый вектор значений C проецируется на ГИС-карту в виде матрицы инспекционного приоритета (Priority for Inspection).
